# Price Checker Chrome Extension

A Chrome extension for tracking product prices across different e-commerce websites.

## Features

- Track product prices from Amazon and eBay
- Save products to a watchlist
- View saved products and their prices
- Support for multiple e-commerce platforms

## Installation

1. Clone this repository or download the ZIP file
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right
4. Click "Load unpacked" and select the extension directory

## Usage

1. Visit a product page on Amazon or eBay
2. Click the extension icon in your browser
3. Click "Save to Watchlist" to track the product
4. View your saved products by clicking "View Watchlist"

## Supported Websites

- Amazon
- eBay
